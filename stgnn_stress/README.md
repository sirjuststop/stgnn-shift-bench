# stgnn-stress

Deployment-shift stress testing and architecture recommendation for frozen
spatiotemporal GNN (STGNN) checkpoints.

Artifact accompanying the NeurIPS 2026 Evaluations & Datasets paper
*"Traffic STGNNs across Sensor, City, and Time Shifts: Routing Concentration
Tracks Sensitivity to Sensor Dropout."*

The temporal recommendations use the original normalized error profile. They
are not rankings of masked physical-unit weekday/weekend error.

## Install (from source)

```
pip install -e ./stgnn_stress
```

## Quickstart — architecture recommender

```python
from stgnn_stress import recommend_architecture

rec = recommend_architecture(
    sensor_churn=True,
    city_transfer=False,
    weekend_heavy=False,
)
print(rec.architecture, rec.runner_up, rec.margin, rec.confidence)
```

The recommender loads the frozen decision-tree artifact shipped with the
package (`data/decision_tree.json`). By default it uses the *honest* ranking,
which demotes models whose low apparent fragility on an axis is attributable
to a known artifact (e.g. MegaCRN's adjacency-mediated smoothing on the sensor
axis). Pass `honest=False` to see the raw ranking.

## Shift evaluation harness

```python
from stgnn_stress.shifts import evaluate_checkpoint
report = evaluate_checkpoint("checkpoints/dcrnn_metr-la_seed0.pt")
print(report.summary())
```

This release ships the recommender with the artifact data. The shift
evaluators (sensor dropout / city transfer / temporal split) are staged as a
scaffold; the exact numbers reported in the paper come from
`experiments/stgnn_shift_eval_v2.py` in the paper repository.

## Provenance

- `data/decision_tree.json` — generated by
  `experiments/decision_tree_artifact.py`.
- Underlying metrics — `results/official_adaptive_relation/merged_comparison_table.csv`
  (8 models × 3 seeds, in-distribution and three deployment shifts).
